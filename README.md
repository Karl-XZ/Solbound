# 火星前哨 · 三十个火星日

面向少年宇航员的火星基地生存经营游戏，默认使用可交互的 2D 美式复古科幻卡通生活舱，并保留完整 3D 舱外场景与开场、结局动画。在杰泽罗陨石坑完成 30 个火星日的任务，每天分配电力，在制氧、温室、辐射屏蔽施工与科研之间作出取舍，并应对太阳风暴、沙尘暴和设备故障。

在线体验：http://1.14.46.26/mars/

## 本地运行

项目使用原生 HTML、CSS 和 JavaScript，无需安装前端依赖或构建。

在项目目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8765/ 。需要支持 WebGL 的现代浏览器。

## 游戏操作

- 点击“开始任务”观看开场，或点击“跳过开场”直接进入基地。
- 点击食物箱、水桶、净水机、急救箱、通讯器、墙历和宇航员，查看资源或执行操作；支持鼠标和键盘 Enter / 空格。
- 加餐、饮水、聊天和药品会改善士气；净水消耗 2 格电池、最多恢复 12 点水。各项照护每日最多一次。
- 乘组每日消耗 2.5 点水，士气自然下降 2 点；缺少水或食物时下降更快。水耗尽也会提前结束任务。这些是游戏规则，非真实生理测量值。
- 左侧“今日手册”逐页查看简报、生活记录、物资、乘组照护、电力安排和环境；使用页脚箭头或键盘左右键翻页。
- 左侧“事件档案”按日期回看事件、决定、资源和电力分配。
- 在“电力安排”页使用各系统的增加、减少按钮分配每天的电力。
- 只能在“今日手册 → 电力安排”页点击“确认安排，结束今天”，处理一个双选随机事件后结算并进入下一天；当天的事件、资源和电力安排自动归档。
- 通讯器每天可以额外收听一次双选事件，不推进日期。
- 右上角可在“基地生活”与“舱外看看”之间切换。手机上可横向滑动探索房间，底部资源也可直接打开物品卡片。
- 页面提供指标说明、数据来源和任务报告。

## 项目结构

```text
index.html       页面和界面结构
css/journal.css  双笔记本、分页与响应式界面
css/habitat.css  卡通生活舱、物品卡片、资源 HUD 与事件弹窗
js/habitat.js    SVG 场景、物品热点、角色表情与生活舱界面
js/game.js       游戏状态、资源结算、事件与界面交互
js/world.js      Three.js 场景与动画
js/audio.js      浏览器合成音效
js/data.js       科学常数、事件存档与 NASA DONKI 数据访问
vendor/          Three.js、D3、TopoJSON 和地理数据
deploy/          Nginx 路径配置
```

## 数据与联网

核心 3D 库和地理数据随项目提供。Google Fonts 字体仍通过网络加载，不可用时使用系统字体。

游戏尝试使用 NASA DONKI 公开接口获取近期太阳耀斑，接口不可用时自动使用内置事件存档。代码中的 `DEMO_KEY` 是 NASA 的公共演示参数。科学测量与游戏简化值在 `js/data.js` 及页面“数据来源与说明”中标注。

## 部署到 /mars/

将 `index.html`、`css/`、`js/` 和 `vendor/` 放到服务器 `/var/www/mars/`。将 `deploy/mars.conf` 加入 Nginx 对应站点的 `server` 配置；配置假设该站点的 `root` 为 `/var/www`。

检查配置并重新加载：

```sh
sudo nginx -t
sudo systemctl reload nginx
```

访问 `/mars` 会跳转到 `/mars/`。静态文件使用相对路径，可由普通静态文件服务器托管。

## 第三方资源
